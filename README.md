# Организатор массовых мероприятий

Веб-приложение на Python и Flet 0.82.0 для подготовки нескольких мероприятий, ведения гостей и команды, назначения ролей, рассылки писем со сценарием и контроля бюджета. Мероприятия сохраняются локально в браузере пользователя. Python и SMTP работают на сервере.

## Запуск в браузере

Требуется Python 3.10 или новее. Команды выполняются из папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Приложение запускается обычным `ft.run()` с `view=ft.AppView.WEB_BROWSER`: Flet открывает браузер по адресу **http://127.0.0.1:8000**. Если вкладка не открылась автоматически, перейдите по этому адресу вручную. Приложение работает, пока запущен процесс; остановка — `Ctrl+C`. На Linux/macOS окружение активируется командой `source .venv/bin/activate`.

## Локальные данные пользователя

Мероприятия, гости, команда, бюджет и настройки писем сохраняются через [Flet SharedPreferences](https://flet.dev/docs/cookbook/client-storage/) в локальном хранилище браузера на устройстве пользователя. Серверный JSON-файл не читается и не обновляется. Данные разных устройств и профилей браузера независимы; регистрация для этого не требуется.

После закрытия и повторного открытия сайта данные доступны в том же профиле браузера по тому же адресу. Домен, протокол и порт определяют хранилище: `localhost:8000` и `127.0.0.1:8000` имеют разные данные. Очистка данных сайта удаляет мероприятия; в приватном режиме хранилище обычно исчезает после закрытия сеанса. Другой браузер или устройство не получают данные автоматически.

На странице выбора мероприятий доступны **«Экспорт JSON»** для скачивания резервной копии на устройство и **«Импорт JSON»** для переноса данных. Импорт добавляет мероприятия как новые копии и не заменяет существующие. Поддерживается прежний формат одного мероприятия. Старый файл `data/event_data.json` оставлен без изменений: чтобы перенести его содержимое в свой браузер, выберите этот файл через «Импорт JSON». Автоматически выдавать старые общие данные новым посетителям приложение не будет.

Объём сохраняемых данных и импортируемого JSON ограничен **2 МБ**. При отказе браузера, нехватке места или повреждённом JSON приложение сообщает об ошибке, а не показывает успешное сохранение. Flet 0.82 кэширует настройки во вкладке: редактируйте данные в одной вкладке, а после работы в другой обновляйте страницу. Проверка конфликтов не заменяет обновление этого кэша.

Постоянное хранение локальное, но приложение остаётся динамическим: данные текущего сеанса передаются по соединению Flet и обрабатываются **в памяти сервера** для интерфейса и рассылки. Это не автономное приложение, в котором данные никогда не покидают устройство.

Пароль приложения почты и выбранный сценарий хранятся только в памяти текущего сеанса и не включаются в резервные копии. Файл до **5 МБ** выбирается диалогом браузера и передаётся на сервер содержимым. Почтовое вложение отправляется из памяти без временного файла на сервере. При переходе к другому мероприятию пароль и файл очищаются. В новом сеансе их нужно указать заново.

В Flet 0.82 выбор файлов через серверный обработчик может ограничиваться Safari/iOS. Для загрузки сценария используйте Chrome, Edge или Firefox на компьютере.

Светлая и тёмная темы автоматически выбираются по настройкам устройства. При смене системной темы оформление обновляется без перезапуска приложения и потери введённых данных.

На экранах уже 760 пикселей разделы доступны через нижнюю панель. Изменение размера окна не пересоздаёт формы. Адреса разделов поддерживают прямое открытие и обновление страницы; мероприятие доступно по ссылке только в браузере, где оно сохранено.

## Запуск на сервере или в локальной сети

```powershell
$env:FLET_SERVER_IP = "0.0.0.0"
$env:FLET_SERVER_PORT = "8000"
python main.py
```

С другого устройства откройте `http://<IP-сервера>:8000`. Порт должен быть доступен в настройках сети и брандмауэра. Flet сам учитывает переменные `FLET_SERVER_IP` и `FLET_SERVER_PORT`. На сервере без браузера можно дополнительно установить `FLET_FORCE_WEB_SERVER=true`.

Запускайте один экземпляр приложения. Сохраняйте постоянный адрес сайта, чтобы браузер продолжал использовать прежнее локальное хранилище.

Посетители используют собственные локальные мероприятия. Для доступа через интернет используйте HTTPS-прокси, передающий WebSocket-соединения на `/ws`. Серверу нужен исходящий доступ к DNS и SMTP на порту 465 для проверки адресов и рассылки.

Приложение требует работающего Python-сервера; статический хостинг вроде GitHub Pages не подходит для текущего запуска Flet и SMTP-рассылки.

## Алгоритм

1. При входе выбрать существующее мероприятие, добавить новое на отдельной странице либо удалить ненужное после подтверждения.
2. Заполнить название, дату, место и описание мероприятия.
3. Нажать «Добавить гостя» и заполнить ФИО и email на отдельной странице.
4. Нажать «Добавить участника», указать его контакты и роль.
5. Добавлять доходы и расходы через кнопку «Добавить статью»; приложение покажет остаток или дефицит.
6. В разделе «Рассылка» выбрать Gmail, Яндекс Почту или Mail.ru, следовать инструкции для выбранного сервиса и ввести адрес и пароль приложения.
7. В разделах «Письмо гостям» и «Письмо команде» отредактировать тему и текст, проверить «Предпросмотр» и нажать «Сохранить настройки и тексты».
8. Выбрать сценарий кнопкой «Выбрать файл» и отправить гостям приглашения, а команде — уведомления с ролями и сценарием во вложении.

## Тексты писем

У каждого мероприятия свои тексты писем гостям и команде. Можно написать обычный текст или использовать подстановки: `{name}` — ФИО получателя, `{email}` — его адрес, `{event_name}` — название мероприятия, `{date}` — дата, `{place}` — место, `{description}` — описание, `{role}` — роль участника команды. Обычные фигурные скобки записываются как `{{` и `}}`.

Предпросмотр использует первого получателя из соответствующего списка, а если список пуст — пример. «Стандартный текст» возвращает исходную тему и текст в редактор; для сохранения результата нажмите «Сохранить настройки и тексты». Перед выходом из раздела сохраняйте изменения. При отправке настройки и тексты сохраняются автоматически. Пустые темы, тексты и неизвестные подстановки не допускаются.

## Почтовые сервисы

Сервис выбирается вручную, поэтому можно использовать и почту на собственном домене, обслуживаемую выбранным провайдером. Получатели могут пользоваться любыми почтовыми сервисами. Приложение подключается к SMTP по SSL/TLS на порту 465.

| Сервис | SMTP-сервер | Настройка доступа |
| --- | --- | --- |
| Gmail | `smtp.gmail.com` | Включить двухэтапную аутентификацию и создать [пароль приложения](https://support.google.com/accounts/answer/185833?hl=ru). |
| Яндекс Почта | `smtp.yandex.ru` | Разрешить почтовые программы и пароли приложений в настройках почты, создать пароль для почты в Яндекс ID. [Инструкция Яндекса](https://yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others). |
| Mail.ru | `smtp.mail.ru` | Привязать телефон, в настройках безопасности создать пароль для внешнего приложения с доступом «Только отправка писем в Почте». [Инструкция Mail](https://help.mail.ru/mail/login/mailer/). |

Подробная инструкция со ссылками отображается прямо в «Рассылке» и меняется при выборе сервиса. При смене сервиса поле пароля очищается. Ранее сохранённые мероприятия получают стандартные тексты при загрузке.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Проверки используют имитацию хранилища браузера и SMTP, не отправляют настоящие письма. Проверяются изоляция профилей, повторная загрузка данных, ошибки сохранения, импорт/экспорт, вложения из памяти и адаптивная навигация. Проверка HTTP/WebSocket запускает настоящий Flet и имитирует ответы браузера на запросы SharedPreferences.

## Структура

- `main.py` — точка входа;
- `Backend/attachments.py` — браузерные вложения в памяти;
- `Frontend/app.py` — интерфейс;
- `Backend/storage.py` — локальное хранилище браузера и проверка JSON;
- `Backend/services.py` — проверка email, бюджет и почтовая рассылка.
- `Backend/mailing.py` — почтовые сервисы, шаблоны и подстановка данных;
- `Frontend/mail_help.py` — инструкции по подключению почты.

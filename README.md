# Организатор массовых мероприятий

Приложение на Python и Flet 0.82.0 для подготовки нескольких мероприятий, ведения гостей и команды, назначения ролей, рассылки писем со сценарием и контроля бюджета.

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

Данные автоматически сохраняются в `data/event_data.json`. Пароль приложения Gmail хранится только в памяти. Файл сценария выбирается системным диалогом — вводить путь вручную не нужно.

Светлая и тёмная темы автоматически выбираются по настройкам устройства. При смене системной темы оформление обновляется без перезапуска приложения и потери введённых данных.

## Алгоритм

1. При входе выбрать существующее мероприятие, создать новое через диалоговое окно либо удалить ненужное после подтверждения.
2. Заполнить название, дату, место и описание мероприятия.
3. Добавить гостей с ФИО и email.
4. Добавить участников и назначить каждому роль.
5. Заполнить доходы и расходы; приложение покажет остаток или дефицит.
6. Ввести Gmail и пароль приложения, выбрать сценарий кнопкой «Выбрать файл».
7. Отправить гостям приглашения, а команде — уведомления с ролями и сценарием во вложении.

## Структура

- `main.py` — точка входа;
- `Frontend/app.py` — интерфейс;
- `Backend/storage.py` — JSON-хранилище;
- `Backend/services.py` — проверка email, бюджет и почтовая рассылка.
